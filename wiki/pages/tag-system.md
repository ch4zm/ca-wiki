# Tag System

## Description

**In rule 110.** Cook's universality proof for [[rule-110](pages/rule-110.md)] encodes a
*cyclic* tag system in the periodic block to the right of the computation.[^1] (The
[[aucm-ch12-linear-cellular-automata-and-decidability](pages/aucm-ch12-linear-cellular-automata-and-decidability.md)] chapter does not define the cyclic variant.)
