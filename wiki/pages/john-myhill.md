# John Myhill

## Description

John Myhill wrote "The converse of Moore's Garden-of-Eden theorem" (1963) at Stanford
University, with support from NSF grant G19001.[^1] The note proves that two
indistinguishable configurations are necessary, not only sufficient, for
[[garden-of-eden](pages/garden-of-eden.md)] configurations, completing the
[[garden-of-eden-theorem](pages/garden-of-eden-theorem.md)] begun by
[[edward-f-moore](pages/edward-f-moore.md)].[^2]

**Earlier work on self-reproduction.** Moore cites two unpublished Myhill items, not read
here:[^3]

- "Self-reproducing automata" (Institute for Advanced Study typescript, circa 1959), which
  in Moore's description partly describes a model between von Neumann's kinematic and
  tessellation models ([[kinematic-self-reproduction](pages/kinematic-self-reproduction.md)],
  [[cellular-automaton](pages/cellular-automaton.md)]).
- "Possibilities of favorable mutation in self-reproducing automata" (University of
  Michigan lecture notes, June 1960). Moore says it proves from axioms, using recursive
  function theory, that machines can build improved versions of themselves, where
  "improved" means able to print out larger classes of true theorems. He adds that this may
  interest a logician more than a biologist.

**Later citation.** Kari (2005) states the Garden-of-Eden theorem as "G_F is injective if
and only if G is surjective" and credits its two directions to Moore and Myhill.[^4] (Own
reasoning: Myhill's direction is G_F injective ⇒ G surjective.)
