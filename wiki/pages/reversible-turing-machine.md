# Reversible Turing Machine

## Description

**In cellular automata.** Because reversible Turing machines (RTMs) can be universal, Morita and Harao (1989) obtained
universal 1D [[reversible-cellular-automaton](pages/reversible-cellular-automaton.md)]s by
simulating them (reported by Kari).[^1]
